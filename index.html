    Cara Cek IP Manual

    Jika pemindai otomatis diblokir oleh sistem keamanan jaringan, ikuti langkah ini di PC/Laptop yang terhubung ke printer:

    1. Tekan tombol Windows + R di keyboard.
    2. Ketik cmd lalu tekan Enter.
    3. Di layar hitam, ketik ipconfig dan Enter.
    4. Cari tulisan IPv4 Address (192.168.xxx.xxx). Masukkan angka tersebut ke aplikasi ini.
