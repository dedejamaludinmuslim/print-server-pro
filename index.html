    Bantu Cari IP Server

    Tombol langsung ke pengaturan Wi‑Fi tidak bisa dijamin bekerja di semua browser, HP, dan Windows. Karena itu, aplikasi hanya menampilkan panduan cepat berikut.

    Windows
    1. Tekan Windows + R.
    2. Ketik cmd, lalu Enter.
    3. Ketik ipconfig.
    4. Lihat IPv4 Address Wi‑Fi.
    Android
    1. Buka Pengaturan → Wi‑Fi.
    2. Ketuk jaringan yang sedang dipakai.
    3. Lihat detail IP Address atau Gateway.
    iPhone / iPad
    1. Buka Settings → Wi‑Fi.
    2. Ketuk ikon i pada jaringan aktif.
    3. Lihat IP Address dan Router.
