    Bantu Cari IP Server

    Mulai dengan Cari Cepat. Jika belum ditemukan, pindai prefix jaringan Wi-Fi dan LAN. Deteksi tidak dapat menembus firewall, VLAN, client isolation, atau jaringan yang tidak memiliki rute.

    Windows
    1. Tekan Windows + R.
    2. Ketik cmd, lalu Enter.
    3. Ketik ipconfig.
    4. Lihat IPv4 Address pada adapter Wi-Fi maupun Ethernet.
    Android
    1. Buka Pengaturan → Wi‑Fi.
    2. Ketuk jaringan yang sedang dipakai.
    3. Lihat detail IP Address atau Gateway.
    iPhone / iPad
    1. Buka Settings → Wi‑Fi.
    2. Ketuk ikon i pada jaringan aktif.
    3. Lihat IP Address dan Router.
    Jika Wi-Fi terdeteksi tetapi kabel tidak
    1. Bandingkan tiga blok awal IP kedua perangkat.
    2. Pastikan profil Windows PC server adalah Private/Domain dan TCP 3000 diizinkan.
    3. Periksa VLAN, AP/client isolation, dan routing antar-subnet pada router/switch.
