    Cara Cek IP Manual

    Jika pemindai otomatis diblokir, ikuti langkah ini di PC Server:

    2. Ketik cmd lalu tekan Enter.
    3. Di layar hitam, ketik ipconfig dan Enter.
    4. Cari baris IPv4 Address (contoh: 192.168.x.x). Masukkan ke aplikasi ini.
